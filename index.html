Methode: Energie-balans per effort: CdA = (P·t − m·g·Crr·d − m·g·Δh) / (½·ρ·v_air²·d). Luchtdichtheid ρ via Open-Meteo Archive API per effort. Effectieve luchtsnelheid: v_air = v_rijder + v_wind·cos(windhoek − segmentrichting). Wind uit de rijrichting = headwind (positief), wind mee = tailwind (negatief). Efforts zonder vermogensdata worden overgeslagen.
